# Repository Structure

The Enterprise IDP repository is organized into the following directories:

| Directory | Purpose |
|---|---|
| `architecture` | Platform architecture files |
| `azure-devops` | Azure DevOps pipeline definitions |
| `backstage` | Backstage developer portal application |
| `diagrams` | Architecture and workflow diagrams |
| `documentation` | General project documentation |
| `github-actions` | GitHub Actions workflows |
| `kubernetes` | Kubernetes manifests |
| `monitoring` | Monitoring configuration |
| `scripts` | Automation scripts |
| `terraform` | Azure infrastructure as code |

## Backstage Directory

The `backstage` directory contains:

- Frontend application
- Backend application
- Catalog metadata
- TechDocs documentation
- Plugin configuration
- Application configuration
