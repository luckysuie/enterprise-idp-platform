# Developer Onboarding

## Prerequisites

Developers require:

- GitHub account
- Azure access
- Git
- Docker
- Node.js
- Terraform
- Azure CLI
- kubectl

## Onboarding Process

1. Obtain access to the GitHub organization.
2. Obtain access to the required Azure subscription.
3. Sign in to the Backstage portal.
4. Search for the required application in the Software Catalog.
5. Read the project documentation.
6. Use an approved software template to create a new application.
7. Deploy the application through the approved CI/CD workflow.
8. Monitor the application through the platform tools.
