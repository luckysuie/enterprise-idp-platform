# Project Overview

## Purpose

The Enterprise Internal Developer Platform provides developers with a centralized portal for accessing software services, documentation, infrastructure templates, deployment workflows, and operational information.

## Objectives

- Improve developer productivity
- Standardize application onboarding
- Automate Azure infrastructure provisioning
- Simplify AKS deployments
- Centralize technical documentation
- Provide self-service capabilities
- Improve visibility across applications and infrastructure

## Core Technologies

- Backstage
- Microsoft Azure
- Azure Kubernetes Service
- Azure Container Registry
- Azure Key Vault
- Terraform
- GitHub Actions
- Azure DevOps

## Current Project Status

The Backstage application has been deployed locally on an Azure Ubuntu virtual machine.

The following capabilities are currently available:

- Backstage frontend and backend
- GitHub integration
- Software Catalog
- Enterprise IDP catalog component
- TechDocs
